**What should a future software engineer or an applied researcher focus on?
**
Given the rapid advance in LLMs, AI agents, and loop engineering, future software engineers or applied researchers can focus on developing the following set of skills to maintain their value.

    - Gain deep fundamental knowledge and domain expertise. Goal is to understand what an agent is doing.
    
    - Build loops and workflows fluently and make them reliably accomplish a designated goal.
    
    - Own a domain and its problems. Don't ask your manager what to do next. Rather, come up with what should be done next.
    
    - Design organization of agents. Be a leader to a 100 to 10K or more virtual agents. Learn to organize them effectively.
    
    - Develop taste and judgement to guide agents and robust ability to verify outcome
    
    - Decide which problems to attack with 1000s of agent hours

We should stop measuring juniors primarily by experiments run, code shipped, or papers implemented, and start deliberately training "problem → loop → evidence → decision" ownership.
